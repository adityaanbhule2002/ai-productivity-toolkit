# Template: Resume bullet

## Template

```
Rewrite this task as one strong resume bullet that starts with an action verb: {task}
```

## Fill in

- `{task}`: a plain description of what you did

## Example

```
Rewrite this task as one strong resume bullet that starts with an action verb: Tested prompts on a small AI model in Google Colab and recorded the results
```

## Tested?

Yes (Test 14 in `testing_report.md`). The reply began "Successfully tested prompts on a small AI model in Google Colab, recording...". That is usable, but it starts with an adverb ("Successfully"), not an action verb as the template asks.

## Tips

- Only describe things you really did. The AI will not check the facts for you.
- Edit the result so it sounds like you, and so it is true.
