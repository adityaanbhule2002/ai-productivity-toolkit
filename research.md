# Template: Research helper

## Template

```
Explain {topic} in simple words in {n} bullet points for a beginner.
```

## Fill in

- `{topic}`: what you want explained
- `{n}`: how many bullet points

## Example

```
Explain what an API is in simple words in 3 bullet points for a beginner.
```

## Tested?

Yes (Test 15 in `testing_report.md`). The model gave **3 numbered points**, as asked, but also added an unwanted intro ("Certainly! ... In simpler terms:").

## Tips

- Use this for a first understanding only.
- Small models can be wrong or vague. Check important facts in a trusted source.
